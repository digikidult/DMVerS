2. GitHub Pages：將此資料夾內容（index.html、style.css、app.js、data.js、assets）上傳至儲存庫根目錄，並啟用 Pages。
3. 不需要 npm、建置程序或 API 金鑰。資料與 245 張圖片全部隨檔案提供。
